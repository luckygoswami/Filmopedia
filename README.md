# Filmopedia

**Filmopedia** is an informational platform dedicated to providing comprehensive data about movies. Whether you're interested in film synopses, cast details, genres, or release dates, Filmopedia offers an easy-to-navigate interface for movie enthusiasts.

## Features

- **Extensive Movie Database:** Browse through a large collection of movies and access detailed information.
- **Search Functionality:** Quickly search for movies by title or filter them based on genre or release year.
- **Responsive Design:** Optimized for all screen sizes, offering a smooth experience on both desktop and mobile devices.
- **Detailed Movie Pages:** Each movie page features a synopsis, cast list, release date, and genre breakdown.

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Database:** TMDB API used to fetch details

## Explore Filmopedia

Discover Filmopedia live at: [Filmopedia](https://luckygoswami.github.io/Filmopedia)

Filmopedia is a dynamic platform where you can explore a wide range of movies and access detailed information about them, including synopses, cast, release dates, and genres—all in a user-friendly interface.

### Local Setup

If you prefer to run Filmopedia locally, follow the steps below to get started.

#### Prerequisites

Make sure you have the following:

- A modern web browser such as Chrome, Firefox, or Edge installed on your system.
- Internet connection to fetch movie data from the external API.

#### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/luckygoswami/Filmopedia.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Filmopedia
   ```

3. Open the `index.html` file in your web browser.

That's it! You should now be able to explore the full functionality of the Filmopedia platform locally.

### Usage

- **Search for Movies:** Use the search bar to find movies by title or apply filters like genre or release year.
- **Explore Movie Details:** Click on any movie to see detailed information including the plot, cast, genre, and release date.
- **Navigate:** The platform offers a clean and simple navigation system to browse different sections easily.
